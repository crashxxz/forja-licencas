Iniciar local:
python licenca_servidor.py serve --host 0.0.0.0

MENU SIMPLES:
Abrir o arquivo ABRIR_MENU_LICENCAS.bat

No menu:
1 = criar teste 30 dias
2 = criar teste 3 dias
3 = criar mensal 30 dias
4 = adicionar tempo na mesma chave
5 = listar chaves

Importante:
"Credito" = adicionar tempo na mesma chave.
Exemplo: cliente pagou mais 30 dias -> opcao 4 -> colar chave -> dias 30.
Nao precisa gerar chave nova todo mes.

Produtos:
python licenca_servidor.py products

Criar chave Iguatu Individual:
python licenca_servidor.py create --customer "Cliente" --product igt_individual --months 1 --max-machines 1

Criar chave Iguatu Individual por 3 dias:
python licenca_servidor.py create --customer "Cliente" --product igt_individual --months 0 --days 3 --max-machines 1

Criar chave Juazeiro Individual:
python licenca_servidor.py create --customer "Cliente" --product jua_individual --months 1 --max-machines 1

Criar chave Juazeiro Individual por 3 dias:
python licenca_servidor.py create --customer "Cliente" --product jua_individual --months 0 --days 3 --max-machines 1

Criar chave Juazeiro Empresa:
python licenca_servidor.py create --customer "Cliente" --product jua_emp --months 1 --max-machines 1

Criar chave Juazeiro Empresa por 3 dias:
python licenca_servidor.py create --customer "Cliente" --product jua_emp --months 0 --days 3 --max-machines 1

Renovar:
python licenca_servidor.py renew --key DOCFLOW-XXXX-XXXX-XXXX-XXXX --months 1

Renovar por 3 dias:
python licenca_servidor.py renew --key DOCFLOW-XXXX-XXXX-XXXX-XXXX --months 0 --days 3

Bloquear:
python licenca_servidor.py block --key DOCFLOW-XXXX-XXXX-XXXX-XXXX

Liberar:
python licenca_servidor.py unblock --key DOCFLOW-XXXX-XXXX-XXXX-XXXX

Listar:
python licenca_servidor.py list

Uso:
python licenca_servidor.py usage

Tolerancia padrao apos vencimento:
3 dias.

Configurar no Render, se quiser mudar:
PAYMENT_GRACE_DAYS=3
